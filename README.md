# REVERIE – AI-Powered Quote Collector App 🌙

A beautifully designed dark-themed quote collection app with AI-based personalized recommendations.

## Features
- Explore, save, and manage inspirational quotes
- AI-powered quote recommendations using OpenRouter API
- Favorites and custom filters
- Add and edit your own quotes
- Dark UI with modern design

## Tech Stack
- Flutter & Dart
- Firebase (Authentication + Realtime Database)
- OpenRouter API (AI Integration)
- UI/UX with Material Design
